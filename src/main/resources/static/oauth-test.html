📚 Available Endpoints

Register: POST /api/v1/auth/register
curl -X POST http://localhost:8080/api/v1/auth/register \ -H "Content-Type: application/json" \ -d '{"email":"user@example.com","username":"user","password":"Pass123!"}'
Login: POST /api/v1/auth/login
curl -X POST http://localhost:8080/api/v1/auth/login \ -H "Content-Type: application/json" \ -d '{"email":"user@example.com","password":"Pass123!"}'
OAuth2 Login: GET /oauth2/authorization/google
Open in browser: http://localhost:8080/oauth2/authorization/google

⚠️ Configuration Required

Before testing OAuth2, ensure you have:

1. Set up Google OAuth2 credentials in Google Cloud Console

2. Added environment variables: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET

3. Configured redirect URI: http://localhost:8080/login/oauth2/code/google

4. See AUTH_SETUP.md for detailed setup instructions
